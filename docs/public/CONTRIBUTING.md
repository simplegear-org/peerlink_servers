# Contributing

PeerLink Servers accepts public issues and bug reports in the public source
mirror.

This repository is not the canonical development history. Development is
performed in a separate development repository, and this public repository
contains clean source snapshots for public releases.

Code contributions must not be merged directly into the source mirror unless
they are first incorporated into the canonical development source.

Non-trivial external code contributions require an approved contributor
licensing process.

Until the final contributor agreement is legally approved, maintainers should
not accept non-trivial external code contributions where ownership or relicensing
rights would become ambiguous.
